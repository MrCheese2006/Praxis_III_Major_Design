# Latex Necessary Formatting Files

This folder contains the necessary files to start a new Latex document. They are as follows:
- IEEEannot.bst:
    - Contains the documentation for an annotated bibliography to work with IEEE citations formatting.
- bibliography.bib:
    - A ```.bib``` file for where citations will go. Use citationmachine.net to make the citation, add ```annote = {...}``` for an annotation if necessary.
- latex_doc_format.txt
    - Copy the content into a ```.tex``` file. The skeleton for our documents will show up. 

Copy all documents into the necessary document folder.
